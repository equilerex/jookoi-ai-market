# Evidence

Read when the user challenges a recommendation or asks why. Each claim carries its primary source. Give the user the link when they want to check it.

- **Spec.** [agents.md](https://agents.md/): plain Markdown, any headings, no required fields. Stewarded by the Agentic AI Foundation (Linux Foundation). Adoption counts quoted there are self-reported.
- **Size guidance.** [Claude Code memory docs](https://code.claude.com/docs/en/memory): keep each `CLAUDE.md` under 200 lines, "longer files consume more context and reduce adherence". No measurement published behind it.
- **Length vs compliance.** McMillan, [arXiv:2605.10039](https://arxiv.org/abs/2605.10039), 1,650 Claude Code sessions, file length 25 to 500 lines: no detectable effect of length, rule position or structure on compliance. Having a file at all moved compliance from 0% to 67.7%. Compliance decayed about 5.6% (odds) per additional function generated within a session, regardless of file design. This is the case for hooks over prose for must-always rules. Solo author, weaker provenance.
- **Cost.** ETH Zurich SRI Lab, [arXiv:2602.11988](https://arxiv.org/abs/2602.11988): context files raised inference cost 19 to 23%. Task success changed -0.5% to -2% for LLM-generated files, +4% for developer-written ones. Repository overviews were unhelpful.
- **What works in practice.** [GitHub blog, Matt Nigh, 2025-11-19](https://github.blog/ai-and-ml/github-copilot/how-to-write-a-great-agents-md-lessons-from-over-2500-repositories/), analysis of 2,500+ repos: effective files have executable commands with flags, testing practice, and real code snippets over prose.
- **Context rot.** [Chroma 2025](https://www.trychroma.com/research/context-rot): all 18 tested models degraded as input grew, well before the context limit. Liu et al. 2023, [arXiv:2307.03172](https://arxiv.org/abs/2307.03172) ("lost in the middle"): retrieval is weakest for content in the middle of context.
- **Nesting.** [Contieri](https://dev.to/mcsee/ai-coding-tip-014-use-nested-agentsmd-files-3iec) and [Boudrias (Datadog)](https://dev.to/datadog-frontend-dev/steering-ai-agents-in-monorepos-with-agentsmd-13g0): root for universal rules, nested only where a subtree differs. Boudrias: proximity discovery fails unless the agent is in that subtree, so root should route to nested files explicitly.
- **Prompt injection.** [NVIDIA AI Red Team, 2026-04-20](https://developer.nvidia.com/blog/mitigating-indirect-agents-md-injection-attacks-in-agentic-environments/): malicious dependency wrote an `AGENTS.md` claiming authority over user instructions and hiding changes in PR summaries. [Backslash Security, 2026-07-06](https://www.backslash.security/blog/openai-codex-injection-in-agents-md-exfiltrating-credentials): Codex `exec` mode followed attacker `AGENTS.md` to exfiltrate credentials.
- **Contradictions.** [Claude Code memory docs](https://code.claude.com/docs/en/memory): conflicting rules are resolved arbitrarily.
- **Emphasis.** Anthropic's prompting best-practices guidance for current Claude models: they follow instructions precisely, and aggressive wording ("CRITICAL", "MUST") written for older models now causes over-triggering. Use normal wording.
